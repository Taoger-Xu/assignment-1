# AI Usage

I used OpenAI Codex as a programming assistant while completing this assignment.

Codex was used to:

- explain the starter repository, Agent/LLM/tool message flow, and assignment requirements;
- help implement and review the Part 1 agent loop, prompt construction, skill loading,
  coding-tool dispatch, and trajectory handling;
- help implement and test Part 2 context compaction and analyze token usage;
- help implement the Part 3 chess tool schemas, chess API helpers, dispatcher,
  programmatic Python sandbox integration, and skill invocation;
- run public tests and Modal integration checks;
- run the required DeepSeek experiments and summarize their saved trajectories;
- review generated files for submission and document remaining limitations.

I reviewed the generated code and explanations throughout the process. The language
model used by the assignment agents was DeepSeek Flash through an OpenAI-compatible
API. Modal was used for remote sandbox execution. The requested GPT-OSS observation
experiments were not run because the configured provider did not offer that model.
